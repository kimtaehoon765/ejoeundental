## 비공개 이전 순서

1. 비공개 GitHub 저장소 또는 인증된 전용 저장공간을 준비합니다. 현재 공개 저장소에 비밀번호·인증 토큰을 저장하지 않습니다.
2. 위 20개 파일을 비공개 공간에 **먼저 복사**하고, 페이지 간 링크 및 점검대장의 브라우저 저장·CSV 내보내기를 확인합니다.
3. 전문 임상자료 중 환자용이 아닌 문서도 추가 분류합니다. 환자용 약물·질환 정보는 공개로 유지합니다.
4. 서버 측 인증 또는 인증된 호스팅으로 접근을 제한하고, 로그아웃 상태에서 직접 URL 접근이 차단되는지 확인합니다.
5. 비공개 자료실에서 20개 페이지와 검색 기능이 정상 작동하는지 검증한 **다음에만** 공개 배포에서 원본 파일을 제거합니다.
6. 공개 저장소의 과거 커밋 기록과 검색엔진 캐시에는 원본이 남을 수 있습니다. 비밀정보가 들어 있다면 별도 조치가 필요합니다.
7. 환자용 사이트의 공개 링크·사이트맵·검색 인덱스에서 전용 자료를 제외한 상태를 유지합니다.

## 주의

- GitHub Pages 등 정적 호스팅에서 자바스크립트 비밀번호 창만 덧씌우는 방식은 비공개가 아닙니다.
- 장비 점검대장은 브라우저 로컬 저장소에 입력 데이터가 남을 수 있으므로, 새 도메인으로 옮기기 전에 CSV 백업을 확인해야 합니다.
- 이 문서는 이전 체크리스트이며, 비공개 자료실이 구축되었다는 의미가 아닙니다.
