# 이조은치과 홈페이지 장기 고도화 로드맵 (2026-10-20)

## 북극성 목표
환자가 실제로 이해하고 신뢰하며 빠르게 필요한 진료정보를 찾을 수 있는 국내 최상위 수준의 소형 치과 홈페이지를 지향한다. '상위 1%'는 목표이지 검증된 순위나 보장된 검색 노출이 아니다. 경쟁 사이트 표본과 평가 기준을 정한 뒤 객관적으로 측정한다.

## 고정 원칙
- 원장이 직접 검진·진단하고 필요한 치료부터 설명한다.
- 자연치아 보존, 직접 시행하는 잇몸치료, 재신경치료, 건강보험 진료, 치경부마모증 GI 수복을 중심으로 한다.
- 의료광고 규정·개인정보·의학적 정확성 우선. 치료 효과 보장, 무통 보장, 과장 비교, 가짜 리뷰, 자격·실적 추정 금지.
- 지역 정보는 청천동 중심, 산곡동·산곡역·부평구 등 실제 접근 가능한 범위에서 자연스럽게 안내한다.
- 금·토요일 격주 운영은 해당 주차를 추측하지 않고 방문 전 전화 확인을 안내한다.
- 도메인 이전·DNS는 사용자가 정한 일정과 별도 승인 없이 변경하지 않는다.

## 우선순위와 단계

### 0단계: 현황 측정과 회귀 테스트 (최우선)
- 페이지 목록/검색 인덱스/사이트맵 자동 대조: 누락·404·중복 canonical·noindex 확인.
- 내부 링크와 앵커 존재 여부, 깨진 이미지, HTML 기본 유효성, JSON-LD 파싱 자동 검사.
- 모바일 360/390/430px, 태블릿, 데스크톱에서 주요 화면 캡처와 사용성 점검.
- Lighthouse 및 실제 방문 데이터(가능할 때)로 LCP, INP, CLS, 접근성 기준선 기록.
- 검색 유입은 네이버 서치어드바이저·구글 서치콘솔의 실제 수치로만 판단.
- 완료 기준: 반복 실행 가능한 점검표 및 주요 결함 목록 확보.

### 1단계: 환자 사용성·속도·접근성
- 첫 화면에서 전화, 진료시간·오시는 길, 주차, 주요 증상으로 1~2회 탭 내 이동.
- 모바일 터치 영역 최소 44px, 글자 대비, 키보드 포커스, 제목 구조와 스크린리더 라벨 점검.
- 중복 CTA·불필요한 반복 문장 줄이고 건강정보의 관련 글 탐색 경로 개선.
- 이미지 크기·포맷, 폰트, CSS/JS 캐시, 불필요한 외부 요청 점검.
- 목표: 주요 템플릿의 모바일 Lighthouse 성능·접근성 각 90+를 지향하되 실제 측정 후 확정.

### 2단계: 임상 콘텐츠 품질 체계
- 진료 분야별 허브 → 증상 → 검사 → 치료 선택지 → 치료 후 주의사항의 일관된 정보 구조.
- 건강정보에 작성·의학적 검토 날짜, 담당자, 참고 근거, 일반정보 면책을 명확히 표기(실제 확인한 경우에만).
- 복용약·전신질환: 임의로 약 중단하지 않도록 안내하고 위험 증상 및 진료 필요 상황을 분명히 한다.
- 치료·보험 정보는 급여 기준, 환자 상태, 시점에 따라 달라짐을 표시하고 정기 검토.
- 유사·중복 페이지 통합 검토; 얇은 키워드 페이지 대량 생산 금지.

### 3단계: 지역 검색 SEO·AI 검색 GEO
- 페이지별 고유 검색 의도, 제목·설명·H1, canonical, OG, 구조화 데이터 일관성 확인.
- 실제 진료 내용과 동일한 Naver Place 정보, 진료시간, 주소, 전화번호 유지.
- 산곡동·산곡역·청천동을 문맥에 맞게 사용; 지역명 나열/검색 순위 조작 금지.
- 주요 질문에 짧고 명료한 직접 답변과 상세 설명을 함께 제공.
- 측정: 브랜드/비브랜드 유입, 노출·클릭·CTR, 주요 페이지 색인, 전화/길찾기 클릭(동의 기반·개인정보 최소화).

### 4단계: 신뢰·전환·운영 안정성
- 의료진·진료 원칙·장비 및 실제 서비스 정보를 사실에 근거해 공개.
- 지도, 교통, 3시간 무료주차 조건, 격주 금·토요일 일정 안내 정확성 유지.
- 개인정보 수집 최소화, 보안 헤더·외부 링크·접근성·법적 고지 정기 검토.
- 변경 시 검증→커밋→배포 확인→모바일 재검증 절차를 고정.

## 작업 우선순위 규칙
1. 깨진 기능/의학적 위험/잘못된 시간·위치 안내
2. 모바일에서 이용 불편한 핵심 경로
3. 중복·오류 콘텐츠와 내부 링크
4. 검색 의도 및 구조화 데이터
5. 디자인 미세 조정과 신규 콘텐츠

## 월간 평가표
- 기술: 내부 링크 오류 0, 사이트맵 누락 0, 구조화 데이터 파싱 오류 0.
- UX: 모바일 핵심 경로 탭 수, 터치 영역, 실제 사용자 피드백.
- 성능: 모바일 LCP·INP·CLS, Lighthouse 측정값(측정 환경·날짜 포함).
- 콘텐츠: 검토 완료율, 근거·최종 검토일, 중복률.
- 검색: 실제 도구의 클릭·노출·색인 추세. 특정 순위 또는 '상위 1%' 달성 선언은 외부 비교 근거 확보 전 금지.
