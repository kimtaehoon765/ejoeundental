## 1. Google Search Console
1. Google Search Console에 로그인하여 URL 접두어 속성 `https://ejoeundental.pages.dev/`이 있는지 확인합니다.
2. 없다면 URL 접두어 속성을 추가하고 소유권을 확인합니다. 홈페이지 소스에는 기존 `google-site-verification` 메타 태그가 있으나, **이 태그가 현재 로그인 계정에 유효한지는 Search Console에서만 확인할 수 있습니다.**
3. 색인 생성 → Sitemaps에서 `https://ejoeundental.pages.dev/sitemap.xml`을 제출하거나 기존 제출 상태를 확인합니다.
4. URL 검사에서 홈페이지와 아래 네 페이지의 색인 상태, 마지막 크롤링, 선택된 표준 URL을 확인합니다.
   - https://ejoeundental.pages.dev/gum-treatment.html
   - https://ejoeundental.pages.dev/retreatment.html
   - https://ejoeundental.pages.dev/cervical-abrasion.html
   - https://ejoeundental.pages.dev/insured-care.html
5. 미색인이라면 검사 결과에 표시되는 구체적 원인을 먼저 확인합니다. 단순히 검색 결과에서 보이지 않는다는 이유만으로 미색인으로 단정하지 않습니다.

## 2. 네이버 서치어드바이저
1. 네이버 서치어드바이저에 로그인하여 현재 Pages 주소가 사이트로 등록되어 있는지 확인합니다.
2. 등록된 사이트의 소유확인 상태를 확인합니다. 확인용 메타 태그나 HTML 파일은 **서치어드바이저에서 실제 발급받은 값**만 사용합니다.
3. 요청 → 사이트맵 제출에서 `https://ejoeundental.pages.dev/sitemap.xml`을 제출하거나 기존 제출 상태를 확인합니다.
4. 웹페이지 수집 요청·사이트 진단 기능에서 홈페이지와 핵심 진료 페이지의 처리 결과를 확인합니다. 메뉴 명칭은 서비스 화면에 따라 다를 수 있습니다.
