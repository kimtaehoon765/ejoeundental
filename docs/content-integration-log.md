# 이조은치과 신규 자료 → 홈페이지 반영 대장

**적용 시작: 2026-11-06 (KST)**

이 문서는 원장이 이후 제공하는 블로그 글, 캡처, 진료 설명, 그림 수정 요청의 반영 이력을 한곳에서 추적하기 위한 기록입니다. 이전에 접수된 자료 전체를 소급해 반영 완료로 간주하지 않습니다.

## 반영 상태 기준

- **접수**: 원장이 전달한 자료 또는 수정 요청을 확인함. 아직 홈페이지 수정 증거 없음.
- **확인 중**: 기존 페이지·원고와 겹치는지 대조 중. 새로 발행할 필요가 없을 수 있음.
- **코드 반영**: 실제 HTML/콘텐츠 JSON/이미지 파일을 GitHub에 저장하고 커밋을 확인함.
- **검사 통과**: 해당 커밋의 빌드 및 품질검사를 확인함. 아직 공개 여부와 다름.
- **실사이트 확인**: 공식 `https://ejoeundental.com`에서 변경 페이지·이미지가 제공되고 배포 커밋과 일치함을 확인함.
- **미완료/보류**: 정확한 자료 부족, 의학적 사실 확인, 이미지 제작 또는 배포 확인이 남음. 이유와 다음 확인점을 적음.

## 원칙

1. 받은 자료를 제목·링크 목록에만 쌓아두고 **홈페이지 반영 완료**로 보고하지 않는다. 사용자가 별도로 목록만 원한 경우는 예외로 구분한다.
2. 네이버 블로그 글과 사진을 그대로 홈페이지에 재사용하지 않는다. 사실과 진료 원칙을 검토해 **홈페이지에 맞는 새로운 환자 설명**을 작성하고, 필요한 그림은 원본과 구별되는 구도·표현으로 새로 만든다.
3. 중복 주제는 새 글을 무리하게 증설하지 말고 기존 적합한 진료 페이지·내부 글을 보강한다. 원문 전체를 옮겼다고 단정하지 않는다.
4. 사진/그림 요청은 `assets/` 파일 등록과 실제 HTML `img` 연결을 각각 확인한다. 대화에서 그림을 생성한 사실만으로 사이트에 삽입됐다고 말하지 않는다.
5. 반영 확인에는 실제 수정 파일, GitHub 커밋, 해당 커밋의 CI, Cloudflare Pages 배포/공식 실사이트를 **서로 다른 단계**로 기록한다. 최신 배포 마커가 다르거나 검증이 제한되면 미확인으로 남긴다.
6. 의료 사실·보험 적용은 현행 기준을 확인하고 과장하지 않는다. 환자 사진·개인정보·무단 원본 이미지는 게시하지 않는다.
7. 자료가 여러 건이면 해당 배치의 건수와 완료/미완료 건수를 함께 보고하고, 미완료 항목을 다음 작업 때 식별할 수 있도록 이 대장에 남긴다.
