치과 재료 백과

레진, 글라스아이오노머, 근관치료 재료, 인상재 등 자주 사용하는 재료의 특징과 주의사항을 한눈에 확인하는 진료실 참고자료입니다.

사용 전 확인: 아래 내용은 일반적 특성입니다. 실제 선택·혼합·중합·보관·폐기는 제품별 IFU(제조사 사용설명서), SDS(안전보건자료), 관련 법규 및 환자 상태에 따라 판단해야 합니다. 건강보험 적용 여부도 재료명만으로 결정되지 않습니다.

레진 복합레진

심미적 직접 수복에 사용합니다. 접착·방습·광중합 조건이 중요하며 제품별 적층 두께와 조사 조건을 따릅니다.

대표적인 주의점
수복부 파절, 변색, 중합 부족, 접착 실패
진료실 확인 사항
광중합기 파장·출력과 제품 지침의 적합성, 사용기한·보관조건 확인

글라스아이오노머(GI)

치질에 화학적으로 결합하며 불소 방출 특성이 있습니다. 치경부 등 비교적 낮은 응력이 가해지는 부위에서 고려할 수 있습니다.

대표적인 주의점
초기 수분 오염·건조, 마모, 파절
진료실 확인 사항
분말·액 비율 또는 캡슐 혼합법, 초기 표면 보호, 제조사 지정 경화시간 확인

레진강화형 GI(RMGI)

산-염기 반응과 레진 중합을 활용하는 재료군으로 수복·이장·접착 등에 제품별 적응증이 다릅니다.

대표적인 주의점
불충분한 광중합, 수분 관리, 레진 성분 과민 반응 가능성
진료실 확인 사항
해당 제품의 광조사·표면처리·적응증 확인

접착제·본딩제

치아와 레진 수복물의 접착을 돕습니다. 에칭·프라이밍 방식은 제품별로 다릅니다.

대표적인 주의점
오염, 용매 증발 부족, 도포 과정 오류
진료실 확인 사항
에칭 방식, 도포·건조·광중합 시간, 보관 조건 확인

근관 실러·거타퍼차

근관 충전에서 근관 공간의 밀폐를 돕는 재료입니다. 재료별 경화 특성과 재치료 가능성을 고려합니다.

대표적인 주의점
충전 불량, 과충전, 재료 적합성
진료실 확인 사항
제품별 혼합·경화·보관 조건과 근관 충전 지침 확인

인상재

알지네이트·실리콘 등으로 구강 형태를 기록합니다. 재료마다 작업·경화 시간과 소독 호환성이 다릅니다.

대표적인 주의점
기포, 변형, 찢김, 부정확한 모형
진료실 확인 사항
혼합비, 온도, 트레이 접착, 소독 및 모형 제작 시간 확인

임시충전재

치료 단계 사이 치아를 임시로 봉쇄·보호합니다. 강도·밀폐성·제거 용이성이 제품별로 다릅니다.

대표적인 주의점
탈락, 누출, 교합 간섭
진료실 확인 사항
권장 두께·사용기간·경화 조건 및 환자 안내 확인

합착용 시멘트

크라운·인레이 등의 합착에 사용하며 보철 재료와 유지 형태에 따라 종류를 선택합니다.

대표적인 주의점
탈락, 잔여 시멘트, 접착 실패
진료실 확인 사항
보철 재료별 전처리·접착 조건과 제조사 지침 확인

검색 결과가 없습니다.

재료 관리 공통 점검표

  1. 제품명·제조사·로트·유효기간 확인
  2. 온도·습도·차광 등 보관 조건 확인
  3. 제품별 혼합·작업·경화 시간 확인
  4. 환자의 알레르기·과민반응 이력 확인
  5. 교차오염 방지 및 일회용품 재사용 금지
  6. 잔여 재료·화학물질의 적정 폐기

근거 자료: American Dental Association — Materials for Direct Restorations. 재료의 구체적인 취급 조건은 제조사 자료를 우선하세요.
